WEBSITE KALKULATOR DISKON
=========================

STRUKTUR FOLDER
---------------
website-diskon/
|-- index.php
|-- assets/
|   `-- css/
|       `-- style.css
`-- README.txt

CARA MENJALANKAN DENGAN XAMPP
-----------------------------
1. Install dan buka XAMPP.
2. Jalankan Apache dengan menekan tombol Start.
3. Salin folder "website-diskon" ke dalam folder:
   C:\xampp\htdocs
4. Buka browser.
5. Ketik alamat:
   http://localhost/website-diskon/

ATURAN DISKON
-------------
- Total belanja >= Rp100.000: diskon 10%.
- Total belanja >= Rp50.000 dan < Rp100.000: diskon 5%.
- Total belanja < Rp50.000: tidak mendapat diskon.

CATATAN
-------
- File utama website adalah index.php.
- File desain berada di assets/css/style.css.
- Program ini tidak membutuhkan database.
